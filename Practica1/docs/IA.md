# Uso de Inteligencia Artificial – Práctica 1

## Objetivo

Comprender la creación de tablas, la definición de tipos de datos y la inserción de registros mediante SQL.

## Uso de la IA

Durante esta práctica utilicé principalmente GitHub Copilot como herramienta de apoyo para generar y comprender código SQL. Posteriormente, contrasté las soluciones con los contenidos impartidos en clase para adaptar el código al nivel y la sintaxis de la asignatura.

También utilicé ChatGPT para resolver dudas relacionadas con la organización del proyecto, las bases de datos SQLite y la configuración del entorno de trabajo en Visual Studio Code.

## Aprendizaje y participación

- Comprensión de la estructura de `CREATE TABLE` e `INSERT INTO`.
- Identificación de los diferentes tipos de datos.
- Comprensión del tratamiento de valores `NULL`.
- Diferenciación entre la creación de una tabla y la consulta de sus registros.
- Organización de archivos SQL y bases de datos.

## Reflexión

En esta primera práctica existió una mayor dependencia inicial de la IA para generar código. El proceso posterior de revisión y contraste con los apuntes permitió avanzar hacia una comprensión más autónoma.

Como aspecto de mejora, debo reforzar la capacidad de construir sentencias SQL desde cero sin depender de sugerencias automáticas.
